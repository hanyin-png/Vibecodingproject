# 3 分钟演示视频脚本（含台词）

> 录屏工具：Win+G（Xbox Game Bar）或 QQ 截图录屏都行。要配音，照着台词念，语速放慢。
> 录制前：双击 一键启动.bat，浏览器打开系统，预选 ENG-020。

| 时间 | 画面 | 台词（照念即可） |
|---|---|---|
| 0:00~0:20 | 停在设备台账页 | "各位老师好，我的课程设计题目是《工业设备智能运维与预测性维护平台》。这个系统面向工厂设备运维场景，用的是 NASA 公开的涡扇发动机退化数据集，目标是回答运维最关心的三个问题：设备状态怎么样、还能用多久、坏了修哪里。" |
| 0:20~0:50 | 数据监测页，选 ENG-020 | "系统里管理着 100 台设备。点进数据监测，可以看到这台设备的四路关键传感器曲线——随着循环数增加，温度上升、压力下降，退化趋势非常明显。这些数据都是从 SQLite 数据库里实时查出来的。" |
| 0:50~1:30 | 健康评估页，点"开始评估" | "接下来做健康评估。点击开始评估，后端会提取这台设备最近 20 个循环的传感器统计特征，用训练好的随机森林模型预测剩余寿命。大家可以看到，这台设备只剩 12 个循环，健康度不到 10 分。模型在测试集上的平均误差是 11.8 个循环，我还训练了一个 LSTM 做对比，两者精度相当。" |
| 1:30~2:00 | 预警中心 | "因为剩余寿命低于阈值，系统自动生成了一条严重级别的预警。这里的预警有两个来源：寿命预测驱动的，和孤立森林异常检测驱动的。" |
| 2:00~2:30 | 点"智能诊断" | "对预警点智能诊断，规则引擎开始推理——它发现 s7、s11、s12 等多路传感器异常，命中了 A1 规则：高压压气机退化，这正是这台设备在数据集里的真实故障模式。下面给出了先软后硬的三层排查步骤和维修措施。" |
| 2:30~2:50 | 回预警中心点"生成工单"，去工单页流转两次状态 | "最后形成维修闭环：从预警一键生成工单，诊断建议自动带入，工单状态从待处理、维修中到已完成流转。" |
| 2:50~3:00 | 停在工单页或切到 GitHub 仓库 | "整个系统前后端分离，覆盖机器学习、深度学习、专家系统、数据挖掘四个课程方向，14 项自动化测试全部通过。我的演示完毕，谢谢老师。" |

## 录制注意

- 录之前完整走一遍彩排，确认没有报错弹窗
- 鼠标移动慢一点，点击前停半秒
- 念错了别停，重念那句，事后剪一刀就行
- 如果超时，砍 0:20~0:50 监测页的台词
